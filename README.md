# StudyBridge-AI

## Project Overview
StudyBridge-AI is an AI-powered study assistant that helps students manage notes, generate personalized study plans, and ask AI questions from uploaded notes. The application is designed to improve learning efficiency through intelligent assistance.

## Features
- AI-powered study planning
- AI Q&A for uploaded notes
- PDF notes support
- Guest Mode access
- Responsive mobile-friendly interface
- Course and task management dashboard

## Technologies Used
- Google AI Studio
- Gemini API
- Firebase Studio
- React
- TypeScript
- HTML
- CSS
